# NSU-RequestGenerator · 成都东软学院请假详情预览工具

基于东软智慧学工请假信息页面的高保真还原，适合做界面演示与样式调试。纯 HTML + CSS + JavaScript，无构建、无第三方依赖。

## 免责声明

- 本项目仅供前端学习与页面样式还原，不连接任何学校系统，不上传任何数据。
- 页面内的姓名、学号、审批人、时间等均为示例数据，严禁用于伪造证明材料或误导他人。
